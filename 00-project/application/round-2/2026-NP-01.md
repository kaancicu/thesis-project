# Custom 2D Physics Engine for Games

## My interpretation of the brief

The aim of this project is to create a custom 2D physics engine for games. The system will simulate rigid bodies and include important parts of a physics simulation such as movement, collision detection, contact generation, and collision response. The project will also include controlled test scenarios to check the correctness, stability, and performance of the physics engine.

## Why I am a good fit for this project

I am interested in game development and I would like to understand how physics systems used in games work internally. This project gives me the opportunity to improve my programming skills while also learning about collision detection, simulation, and the mathematical concepts behind game physics. I am willing to learn the required concepts during the development of the project and build the system step by step.

## Relevant experience and background

I have programming experience from my university courses and I am continuing to develop my software development skills. I have experience learning programming concepts and implementing smaller programs. Although building a physics engine will introduce new concepts for me, I am interested in developing my knowledge of game development, algorithms, and simulation through this project.

## Proposed approach

I would begin by creating a basic simulation loop and representing simple rigid bodies. I would then implement movement and integration, followed by collision detection and collision response. I would initially focus on simple geometric shapes such as circles or axis-aligned boxes to keep the project manageable. After the basic physics system is working, I would create controlled test scenarios and measure its numerical stability, correctness, and performance under different simulation conditions.

## Initial plan

1. Study the basic concepts of 2D rigid-body physics and numerical integration.
2. Define the rigid-body representation and simulation loop.
3. Implement movement and state integration.
4. Implement broad-phase and narrow-phase collision detection.
5. Implement contact generation and collision response.
6. Create controlled test scenes and visualization.
7. Test numerical stability, correctness, and performance.
8. Document the implementation, results, and limitations.

## Additional information

I plan to develop the project incrementally and maintain the source code in this Git repository throughout the project. I will use small test scenarios while developing each part of the physics engine so that individual components can be checked before combining them into the complete simulation.
