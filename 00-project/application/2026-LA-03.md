# Player Feedback Data Warehouse

## My interpretation of the brief

The aim of this project is to create a data warehouse for collecting and analyzing player feedback from different online platforms. The project will use feedback from Counter-Strike 2, Cyberpunk 2077, and Grand Theft Auto V. Data from sources such as Steam reviews and YouTube comments will be collected, processed, and stored in a structured way so that feedback can be compared by game, source, time, language, and evaluation characteristics.

## Why I am a good fit for this project

I am interested in working with databases and learning more about how large amounts of real-world data can be collected, organized, and analyzed. This project would give me an opportunity to improve my database and SQL skills while also learning about data warehouses, ETL processes, APIs, and performance optimization. I also find the use of video game feedback interesting because it provides practical data that can be analyzed in many different ways.

## Relevant experience and background

I have programming and database experience from my university courses and I am continuing to improve my software development skills. I have studied basic database concepts and I am interested in developing a better understanding of SQL and data management. Some parts of the project, such as data warehousing and large-scale ETL processes, will be new to me, but I am willing to learn these concepts step by step during the project.

## Proposed approach

I would first study the available methods for collecting Steam reviews and YouTube comments and create a staging layer for storing the collected data. I would then design the dimensional model of the data warehouse using fact and dimension tables. After that, I would implement an ETL or ELT process to clean, standardize, and load data from the different sources. Once the warehouse is working, I would create analytical SQL queries for comparing feedback by game, source, time, language, and evaluation characteristics. Finally, I would measure the performance of selected queries and investigate suitable optimization methods.

## Initial plan

1. Study data warehousing, dimensional modeling, and ETL/ELT concepts.
2. Investigate methods for collecting Steam reviews and YouTube comments.
3. Design and implement the staging layer.
4. Compare possible dimensional models and design the data warehouse.
5. Implement the ETL or ELT process.
6. Implement incremental data loading and data-quality handling.
7. Create analytical SQL queries for the collected player feedback.
8. Measure and optimize the performance of selected queries.
9. Document the implementation, results, and limitations.

## Additional information

I plan to develop the project incrementally and maintain all source code and documentation in this Git repository. I would begin with a smaller amount of data to verify the collection and loading process before increasing the system to the required scale. This approach would allow me to test each component separately before combining them into the complete data warehouse system.
